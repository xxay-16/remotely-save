# Remotely Save 0.6.0 — S3 / WebDAV Only

> **English below · 中文在后半部分**

---

## English

**This is a trimmed-down fork of [remotely-save/remotely-save](https://github.com/remotely-save/remotely-save). It keeps only Amazon S3 (or S3-compatible) and WebDAV as sync targets.**

### ⚠️ Breaking changes

Support for the following services has been **removed**:

- Dropbox
- OneDrive (App Folder and Full)
- Webdis
- Google Drive
- Box
- pCloud
- Yandex Disk
- Koofr
- Azure Blob Storage

If you were syncing with one of these services, **do not upgrade** — stay on the upstream plugin or on a 0.5.x release.

### What remains

- **Amazon S3** and S3-compatible services (Cloudflare R2 / BackBlaze B2 / MinIO / Tencent COS / ...)
- **WebDAV** (Nextcloud / InfiniCloud / Synology / AList / Nutstore / ...)
- End-to-end encryption (openssl / rclone crypt format)
- Scheduled auto sync and sync on save
- Smart Conflict (PRO feature)
- Import / export settings by QR code (S3 and WebDAV only)

### Technical changes

- ~22,400 lines of service-specific code removed; bundle size reduced from ~4.0 MiB to ~1.3 MiB
- Removed 9 service-specific dependencies (Dropbox SDK, `@azure/*`, Microsoft Graph, Box SDK, pCloud SDK, ...)
- `package-lock.json` is now committed for reproducible builds
- CI: build + test + artifacts on every push; tagged commits automatically produce a GitHub Release with the plugin files

### Install

Download `main.js` (and any other `*.main.js` files), `manifest.json` and `styles.css` from the assets below, then place them into `<your-vault>/.obsidian/plugins/remotely-save/` and enable the plugin in Obsidian.

**As always: back up your vault before syncing.**

## 中文

**本仓库是 [remotely-save/remotely-save](https://github.com/remotely-save/remotely-save) 的精简分支，仅保留 Amazon S3（或 S3 兼容服务）和 WebDAV 两种同步方式。**

### ⚠️ 破坏性变更

以下服务的支持已被**移除**：

- Dropbox
- OneDrive（应用文件夹 / 完整版）
- Webdis
- Google Drive
- Box
- pCloud
- Yandex Disk
- Koofr
- Azure Blob Storage

如果你正在使用上述任一服务同步，**请勿升级**——请继续使用上游插件或 0.5.x 版本。

### 保留的功能

- **Amazon S3** 及 S3 兼容服务（Cloudflare R2 / BackBlaze B2 / MinIO / 腾讯云 COS / ...）
- **WebDAV**（Nextcloud / InfiniCloud / 群晖 / AList / 坚果云 / ...）
- 端到端加密（openssl / rclone crypt 格式）
- 定时自动同步、保存时同步
- 智能冲突合并（PRO 功能）
- 通过二维码导入 / 导出设置（仅 S3 和 WebDAV）

### 技术变更

- 删除约 22,400 行各服务专属代码，构建产物从约 4.0 MiB 降至约 1.3 MiB
- 移除 9 个服务专属依赖（Dropbox SDK、`@azure/*`、Microsoft Graph、Box SDK、pCloud SDK 等）
- `package-lock.json` 纳入版本管理，构建可复现
- CI：每次推送自动构建 + 测试 + 上传产物；打 tag 自动发布 GitHub Release

### 安装

从下方附件下载 `main.js`（及其他 `*.main.js` 文件）、`manifest.json` 和 `styles.css`，放入 `<你的库>/.obsidian/plugins/remotely-save/` 目录，然后在 Obsidian 中启用插件。

**重申：同步前请务必备份你的库。**
